# SIDEKOM, site officiel

Site vitrine statique (HTML, CSS, JavaScript), sans framework.

## Structure

```
sidekom-site/
├── index.html
├── css/styles.css
├── js/main.js
├── assets/favicon.svg
└── README.md
```

## Avant la mise en ligne

1. **Formulaire** : créez un formulaire sur formspree.io, puis remplacez `VOTRE_ID` dans `index.html`.
2. **Réservation** : remplacez `https://cal.com/VOTRE-LIEN` par votre lien Cal.com ou Calendly.
3. **Tarifs** : remplacez les mentions "Tarif à définir" par les vrais prix.
4. **Analytics** : décommentez la ligne Plausible dans `index.html` et mettez votre domaine.
5. **Logo** : quand le designer livre les fichiers, ajoutez-les dans `assets/` et remplacez le texte du wordmark.

## Publier gratuitement

Poussez le dossier sur GitHub, puis connectez le dépôt à Netlify, Cloudflare Pages ou GitHub Pages. Ajoutez ensuite votre domaine.
